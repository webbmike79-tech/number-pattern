# Number Pattern

A tiny Python lab solution: `number_pattern(n)` validates its input and
returns the numbers 1 through n joined with spaces.

```python
>>> from number_pattern import number_pattern
>>> number_pattern(5)
'1 2 3 4 5'
>>> number_pattern(3.5)
'Argument must be an integer value.'
>>> number_pattern(0)
'Argument must be an integer greater than 0.'
```

## Run it

No dependencies — standard library only.

```bash
python3 number_pattern.py
```
